# Resume Project by Isabel Coutinho

A Node.js project deployed to Azure Web App with automated CI/CD workflows.

## Project Setup

- **Node.js Version:** 24.x
- **Package Manager:** npm (using package-lock.json)
- **Deployment:** Azure Web App
- **Tools:** Visual Studio Code, Netlify

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/isabelcoutinhoo1898/Resume-Project-by-Isabel-Coutinho.git
   cd Resume-Project-by-Isabel-Coutinho
   ```

2. Install dependencies:
   ```bash
   npm ci
   ```

3. Run the project:
   ```bash
   npm start
   ```

## Deployment

This project uses GitHub Actions for automated deployment to Azure Web App. See `.github/workflows/` for workflow configuration.
